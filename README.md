# Nexus Tournaments

Aplicación para organizar torneos: servidor en Node.js + Express + TypeScript y cliente en React + Vite + Tailwind.

## Estructura

- `.cursor/rules/` — reglas de los agentes
- `docs/` — documentación metodológica
- `backend/` — servidor
- `frontend/` — aplicación web
- `AGENTS.md` — reglamento para la IA

## Entorno local

Las claves y la URL del backend están en archivos `.env` que no se suben a GitHub.
